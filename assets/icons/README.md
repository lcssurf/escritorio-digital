# Icons

Used in the project README.

- Line icons: [Lucide](https://lucide.dev) (ISC license), recolored.
- Claude, Model Context Protocol and AWS marks: [Simple Icons](https://simpleicons.org) (CC0), recolored. The marks are
  trademarks of their owners and are used only to name those products.
- Slack mark: Slack's own logo, used only to name the Slack integration.
- Stripe and Google Ads marks: drawn after their logos, used only to name those connectors.
